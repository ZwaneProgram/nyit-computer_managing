# Project Overview
Computer shop stock and sales management system.

# Stack
- Vite + React 18 + TypeScript (SPA, no backend yet)
- Plain CSS with design tokens in `src/styles.css` (no UI framework)
- Mock data in `src/data/` — swap for a real API/DB later without touching views
- Commands: `npm run dev`, `npm run build`, `npm run preview`

# Rules
- Use Thai language UI
- Prioritize fast workflow UX
- Keep components modular
- Avoid unnecessary complexity
- Mobile responsive required

# Workflow
- Plan before implementation
- Verify before finishing
- Prefer minimal clean UI
